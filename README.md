# Mohsenul Kabir Mithun — Portfolio Website

A modern, responsive portfolio website showcasing skills, experience, and projects.

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, glassmorphism, modern animations
- **JavaScript** — Vanilla JS with modular interactions
- **Bootstrap 5.3** — Responsive grid & components
- **AOS** — Scroll animations
- **Typed.js** — Typing animation
- **Swiper** — Touch slider for testimonials
- **Isotope** — Filterable portfolio grid
- **GLightbox** — Lightbox gallery

## Getting Started

1. Clone the repository
2. Open `index.html` in a browser — no build step required
3. For the contact form, deploy to a PHP-enabled server

## Customization

- **Colors & Theme**: Edit CSS custom properties in `assets/css/main.css` (`:root` section)
- **Content**: Edit `index.html` sections directly
- **Portfolio items**: Add/modify items in the portfolio section of `index.html`

## Deployment

This is a static site. Deploy to any hosting platform:

- GitHub Pages
- Netlify
- Vercel
- Any web server
